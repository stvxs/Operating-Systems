# Практическая работа №2 - Использование простых команд Linux

***

## Цель работы

Изучить команды Linux для создания каталогов и файлов, редактирования текста, поиска информации и обработки потоков данных.

## Оборудование и программное обеспечение

- Виртуальная машина с Debian GNU/Linux 13.
- Терминал Linux.
- Текстовый редактор nano.

***

## Ход выполнения работы

### 1. Создание каталога `work`

С помощью команды `mkdir` был создан каталог `work` в домашней директории.

```bash
mkdir ~/work
```

Затем был выполнен переход в созданный каталог и проверен текущий путь.

```bash
cd ~/work
pwd
```

### 2. Создание и заполнение файла `file.txt`

С помощью команды `touch` был создан пустой файл `file.txt`.

```bash
touch file.txt
```

Для редактирования файла был открыт текстовый редактор `nano`.

```bash
nano file.txt
```

Текст был введён вручную. Каждое предложение было записано с новой строки. После ввода текста файл был сохранён.

Содержимое файла было проверено командой:

```bash
cat file.txt
```

### 3. Переименование файла

С помощью команды `mv` файл `file.txt` был переименован в `book.txt`.

```bash
mv file.txt book.txt
```

Наличие файла было проверено командой:

```bash
ls
```

Содержимое файла было проверено командой:

```bash
cat book.txt
```

### 4. Поиск предложений со словом `was`

С помощью команды `grep` были найдены строки, содержащие слово `was`. Результат был сохранён в файл `was.txt`.

```bash
grep "was" book.txt > was.txt
```

Содержимое нового файла было проверено командой:

```bash
cat was.txt
```

<img width="700" alt="image" src="https://github.com/user-attachments/assets/53ccf70e-d7ae-45f5-ab39-3a76f1a25f27" />

***

### 5. Подсчёт количества букв `n`

С помощью команд `cat`, `grep` и `wc` было подсчитано количество вхождений буквы `n` в объединённом содержимом файлов `was.txt` и `book.txt`.

```bash
cat was.txt book.txt | grep -o "n" | wc -l
```

Результат выполнения команды:

```text
73
```

Наличие обоих файлов было проверено командой:

```bash
ls
```
