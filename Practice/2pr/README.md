# Практическая работа №2 - Простые команды Linux

Практика по работе с файловой системой и потоками данных в Debian GNU/Linux 13.

## Выполненные задания

- Создание каталога `work`.
- Создание и редактирование файла с помощью `nano`.
- Переименование файла с помощью `mv`.
- Поиск строк с помощью `grep`.
- Перенаправление вывода в файл.
- Подсчёт символов с помощью `wc`.

## Используемые команды

`mkdir`, `cd`, `pwd`, `touch`, `nano`, `cat`, `mv`, `ls`, `grep`, `wc`.

Все задания выполнены. Отчёт и скриншоты представлены в репозитории.
