# Практическая работа №3 - Команды администрирования Linux

Практика по работе с процессами и справочной системой в Debian GNU/Linux 13.

## Выполненные задания

- Просмотр дерева процессов с помощью `ps`.
- Поиск процессов, запущенных не от имени `root`.
- Сортировка процессов по использованию памяти.
- Просмотр фоновых заданий с помощью `jobs`.
- Поиск информации в справке `man`.
- Поиск справочных страниц с помощью `apropos`.

## Используемые команды

`ps`, `awk`, `head`, `jobs`, `man`, `apropos`.

## Результат

Все задания выполнены. Отчёт и скриншоты представлены в репозитории.
