# Практические работы

В этой папке собраны практические работы по предмету **«Операционные системы и среды»**.

## Структура

Каждая практическая работа хранится в отдельной папке или файле. В зависимости от задания могут быть добавлены:

- Условия задания
- Команды и примеры их выполнения
- Файлы с выполненной работой
- Отчёты в формате Markdown
- Скриншоты выполнения
- Результаты работы в виртуальной машине Debian

## Цель

Закрепление теоретических знаний и получение практических навыков работы с операционными системами, командной строкой Linux, терминалом и виртуальными машинами.
