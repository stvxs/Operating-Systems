## Задание 1. Отображение процессов в виде дерева

Для отображения процессов в виде дерева используется команда:

```bash
ps -ef --forest
```

- `ps` - отображает информацию о процессах.
- `-e` - выводит все процессы.
- `-f` - отображает подробную информацию.
- `--forest` - показывает иерархию процессов в виде дерева.

**Результат:** процессы отображаются в виде дерева с обозначением родительских и дочерних процессов.

## Задание 2. Поиск процессов, запущенных не от имени root

Для отображения процессов, запущенных не от имени пользователя `root`, используется команда:

```bash
ps -eo user,pid,comm | awk '$1 != "root"'
```

- `ps -eo user,pid,comm` - выводит имя пользователя, идентификатор процесса и название команды.
- `awk '$1 != "root"'` - отбирает процессы, у которых первый столбец не равен `root`.

**Результат:** отображаются процессы, запущенные пользователями, отличными от `root`.

## Задание 3. Поиск пяти процессов, потребляющих больше всего памяти

Для сортировки процессов по использованию памяти используется команда:

```bash
ps aux --sort=-%mem | head -n 6
```

- `ps aux` - выводит информацию о процессах.
- `--sort=-%mem` - сортирует процессы по использованию памяти в порядке убывания.
- `head -n 6` - выводит первые шесть строк, включая заголовок таблицы и пять процессов.

**Результат:** выводятся пять процессов, потребляющих больше всего памяти.

## Задание 4. Поиск фоновых процессов

Для просмотра фоновых и приостановленных заданий текущего терминала используется команда:

```bash
jobs -l
```

Команда `jobs -l` выводит список заданий текущей оболочки с идентификаторами процессов. Если список пуст, значит, в текущем терминале нет таких заданий.

Для просмотра процессов системы используется команда:

```bash
ps -eo pid,stat,comm
```

- `pid` - идентификатор процесса.
- `stat` - состояние процесса.
- `comm` - название команды.


Для выхода из справочной страницы была нажата клавиша `q`. После выхода в терминал была введена команда:


## Задание 7. Поиск справочных страниц по ключевому слову copy

Для поиска справочных страниц по ключевому слову `copy` была использована команда:

```bash
apropos copy
```

Команда `apropos` ищет справочные страницы по ключевым словам в кратких описаниях.

В результате были найдены следующие справочные страницы:

- `cp (1)` - копирование файлов и каталогов.
- `cpio (1)` - копирование файлов в архивы и из архивов.
- `dd (1)` - преобразование и копирование файлов.
- `debconf-copydb (1)` - копирование базы данных debconf.
- `install (1)` - копирование файлов и установка атрибутов.
- `scp (1)` - безопасное копирование файлов.
- `ssh-copy-id (1)` - использование ключей для авторизации на удалённой машине.
- `string_copying (7)` - копирование строк и символов.

**Результат:** с помощью команды `apropos` найдены справочные страницы, связанные с ключевым словом `copy`.
