
# Практика №1 - Простые команды Linux

***

## Цель работы

Изучить основные команды Linux для работы с файлами и каталогами.

***

## Используемые команды

- `cd` - переход между каталогами.
- `ls` - просмотр и сортировка файлов.
- `cat` - просмотр содержимого файлов.
- `grep` - поиск текста в файлах.
- `find` - поиск файлов и каталогов.

***

Выполнены практические задания по работе с командной строкой Debian GNU/Linux.
