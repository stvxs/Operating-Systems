
# ДЗ № 2 - Создание снимков ВМ

## Цель работы

Изучить создание снимков виртуальных машин и восстановление системы в Oracle VirtualBox.

## Выполнение

- Создан снимок виртуальной машины Debian.
- Смоделировано повреждение операционной системы.
- Выполнено восстановление Debian из сохранённого снимка.
- Проверена работоспособность системы после восстановления.

## Результат

Освоен механизм создания и восстановления снимков виртуальной машины.
