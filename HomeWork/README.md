# Домашние задания

В этой папке собраны домашние задания по предмету **«Операционные системы и среды»**.

## Структура

Каждое домашнее задание хранится в отдельной папке или файле. В зависимости от задания могут быть добавлены:

- Условия задания
- Файлы с выполненной работой
- Отчёты в формате Markdown
- Скриншоты выполнения

## Цель

Выполнение домашних заданий для закрепления теоретических знаний и практических навыков работы с операционными системами и командной строкой Linux.
